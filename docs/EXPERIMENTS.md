# Experiments

Lifecycle:

`DRAFT -> REVIEW -> APPROVED -> RUNNING -> PAUSED -> SUCCESS | FAILURE | TERMINATED`

Each experiment records its hypothesis, opportunity and negotiation links, proposed actions, stream, expected revenue, maximum loss/spend, duration, success/kill criteria, owner agent, dates, paper economics, observations, and outcome action. Budget overruns are denied. Completed outcomes produce a postmortem with actions, spend, revenue, P/L, conversion metrics, failures, repeat decision, and reusable lessons.

The same lifecycle supports agent services/research, licensable digital assets, public tasks/bounties, affiliate/content, and bug-bounty work. Stream-specific restrictions are gates on the shared pipeline, not separate services.

Real-demand experiments require durable untrusted evidence, a real two-way negotiation, explicit agreement, and owner go/no-go. Building before agreement is prohibited. Delivery requires a second owner choice of `PAPER` or `REAL`.

The seeded demo is synthetic UI/runtime evidence only. It never represents a real buyer, agreement, acceptance, delivery, payment, or external revenue.
